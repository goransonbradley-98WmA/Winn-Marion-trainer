# Winn-Marion Electrical Training Pro

## Approved project baseline
- Company-branded employee training LMS with oilfield artwork and consistent navigation
- Dedicated mobile-friendly schematic wiring simulators with draggable components, freehand wiring, snapping, zoom/pan and deletion
- Motor control, transformer, LOTO and meter practice modules
- Browser-based Three.js equipment lab, no headset required
- Modular incremental changes only; preserve existing functionality and commit every verified update
